## Веб-интерфейс

В браузере пройден сценарий: свободное описание → неопределенность классификатора → явное подтверждение цели → оборудование / частями / 3 млн / 36 месяцев / без собственного залога → K1 как альтернатива. Проверены причины исключения остальных продуктов.

Заявка заполнена синтетическим профилем. Вход сохранил сумму, срок, цель и данные компании. После отправки проверены одобрение, принятие условий, предварительный текст договора и подтверждение просмотра, моделирование подписи/выдачи, сохраненный документ. Под банковской ролью выполнен запрос дополнительных сведений с комментарием. Лента подхватила отрасль/статус последней заявки; полный текст статьи открыт и визуально проверен.

Снимки в `docs/screenshots/` подтверждают внешний вид отдельных экранов. Работоспособность проверяется живым приложением и API, а не снимками.
